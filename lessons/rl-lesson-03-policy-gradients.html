Policy Gradients & REINFORCE

DQN learned what a state is worth and acted greedily. Policy gradients skip that and optimize the policy itself. One trick — the score function — makes it possible even when the reward is a black box. Get this and PPO, GRPO, and the whole LLM frontier become variations on a theme.

01 The trick that makes it work

The score function

We want to maximize expected return J(θ) = E_{τ∼π_θ}[R(τ)] by gradient ascent. The problem: the thing we sample from depends on θ, so we can’t naively move the gradient inside the expectation. The log-derivative trick fixes it with one identity, ∇p = p·∇log p:

the derivation, 3 moves // expectation is an integral over a θ-dependent density
∇θ J = ∇θ ∫ π_θ(τ) R(τ) dτ = ∫ ∇θπ_θ(τ) R(τ) dτ
// multiply & divide by π — the ∇p = p·∇log p identity
= ∫ π_θ(τ) ∇θ log π_θ(τ) R(τ) dτ
// it’s an expectation again — now estimable by sampling
= Eτ[ R(τ) · Σt ∇θ log π_θ(at|st) ]
Why this is the whole ballgame Look at what survived: the gradient touches only the policy’s log-prob. The reward R(τ) and the environment dynamics are never differentiated — they can be a game engine, a unit-test runner, a human rating. That’s exactly why the same math drives a verifiable-reward LLM: you don’t need a differentiable reward, just a number.

02 The algorithm

REINFORCE is weighted imitation

Drop the expectation, sample trajectories, and you have the entire algorithm:

reinforce updateθ ← θ + α · Gt · ∇θ log π_θ(at|st)

Here’s the intuition that connects it straight to your Karpathy background. Ordinary next-token training maximizes log π(correct token) — plain maximum likelihood. REINFORCE maximizes R · log π(the token you actually sampled). Same gradient shape, one extra scalar:

What no longer flows where In your gym setups the environment was a black box and that felt incidental. Now it’s the point: gradient flows back through the policy network only. The env and reward sit outside the computation graph entirely — they just hand you the scalar that scales the gradient.

03 Making it usable

Baselines kill the variance

REINFORCE is correct but brutally noisy — returns swing wildly between episodes, so the gradient estimate is too. The fix: subtract a baseline b(s) that doesn’t depend on the action. It leaves the gradient unbiased (proof in the exercise) but slashes variance. The best simple choice is the state value V(s) — and then the weight becomes the advantage:

advantage = how much better than averageA(s,a) = Gt − V(s)　　→　　θ ← θ + α · A(s,a) · ∇ log π
04 The architecture

Actor-critic: bolt your value function back on

Where do you get V(s)? You learn it — with a second network, the critic. And a learned value function is exactly the thing DQN already taught you. So actor-critic = the new policy-gradient idea (actor) + the value function you already own (critic) acting as the baseline.

This is the unlock You now have the full template the frontier is built on. PPO = this, plus a clipped update so you can reuse samples without the policy lurching. GRPO = this, but it deletes the critic and uses the average reward of a group of samples as the baseline instead. Same skeleton every time.

06 Check yourself

One exercise

Prove the key claim: subtracting a baseline b(s) that depends only on the state (not the action) leaves the policy gradient unbiased. Why does its contribution vanish in expectation?

SOLVE Reveal the answer ▸

The baseline’s contribution to the gradient is E_a[ b(s) · ∇ log π(a|s) ]. Pull the action-independent b(s) out, and use the same ∇log p = ∇p / p identity in reverse:

b(s) · Σa π(a|s) ∇ log π(a|s) = b(s) · Σa ∇ π(a|s) = b(s) · ∇ Σa π(a|s) = b(s) · ∇ 1 = 0

The probabilities sum to 1, and the gradient of a constant is zero — so the baseline adds exactly nothing to the expected gradient. It can’t bias you. But it can shrink the variance of the sample estimate, which is the entire reason to use it. This is the cleanest example of a deep RL pattern: a term that’s zero in expectation but enormously helpful for the estimator.

Takeaway

Push up the log-prob of actions that beat the baseline, push down the ones that don’t. REINFORCE is that sentence; everything else — actor-critic, PPO, GRPO — is making that one update less noisy and less reckless.
