Anson API

2020 · leadership · a numerai friday-night talk

One of my main contributions to Numerai was helping to build the team. As we scaled the number of people in the company, I realized that we also needed to change the way we communicate, because not everyone was always in the room anymore.

Since almost everyone on the team was technical, I thought that it would be funny to talk about communication in terms of specifying an API, and people liked it!

This was a pretty short presentation, but actually involved an interactive part at the end where I asked everyone to answer some questions to write their own APIs and share them, which made for a really fun Friday night session!
